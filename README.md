# ChocoCraft - Premium Artisan Chocolate Website

A modern, accessible, and performant website for a premium chocolate brand built with vanilla HTML, CSS, and JavaScript following industry best practices.

## 🚀 Features

- **Semantic HTML5** with proper accessibility attributes
- **Modern CSS** with custom properties and BEM methodology
- **Vanilla JavaScript** with ES6+ features and modular architecture
- **Responsive Design** that works on all devices
- **Performance Optimized** with lazy loading and efficient animations
- **Accessibility First** with WCAG 2.1 compliance
- **SEO Friendly** with proper meta tags and semantic structure

## 🚀 Performance Optimizations

1. **Image Optimization**
   - Lazy loading for non-critical images
   - Proper `loading` attributes
   - Fallback handling for missing images

2. **JavaScript Optimization**
   - Debounced scroll handlers
   - Intersection Observer for animations
   - Event delegation where appropriate
   - Passive event listeners

3. **CSS Optimization**
   - Efficient selectors
   - Hardware acceleration for animations
   - Minimal repaints and reflows
