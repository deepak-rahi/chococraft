# ChocoCraft Images

Place the following images in this folder for the website to display properly:

## Required Images:

### Hero Section:
- `hero-chocolate.jpg` - Premium chocolate breaking apart or melting (1920x1080 recommended)

### Product Images:
- `product-truffle.jpg` - Gold truffle collection (800x800 recommended)
- `product-praline.jpg` - Caramel pralines (800x800 recommended) 
- `product-bark.jpg` - Artisan chocolate bark (800x800 recommended)

### Brand Story:
- `artisan-crafting.jpg` - Artisan crafting chocolate or chocolate workshop (600x750 recommended)

## Image Guidelines:
- Use high-quality, professional food photography
- Maintain consistent lighting and color temperature
- Focus on premium, luxury aesthetic
- Ensure images are optimized for web (under 500KB each)
- Use JPG format for photographs

## Fallback:
If images are not available, the website will show placeholder content with chocolate emojis and gradient backgrounds.
